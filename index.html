⚙️ Project Settings

1/5🔗 GitHub Connection

Needs repo scope for private repos. Stored encrypted.
📖 How to create a GitHub PAT
  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Click Generate new token (classic)
  3. Give it a descriptive name (e.g. "SF Pipeline Tracker")
  4. Under Select scopes, check repo (full control of private repositories)
  5. Click Generate token and copy the value immediately
  6. Paste the token into the field above

⚠️ The token is shown only once. If you lose it, you'll need to generate a new one.
Direct link: https://github.com/settings/tokens

3/5🔀 Pipeline Environments

Define your environment branches from left (earliest) to right (production).

📖 What are Gearset-style branches?

Gearset uses a specific branch naming convention: gs-pipeline/<env-name>_-_<display-name>

Examples:

  • gs-pipeline/dev_-_Development
  • gs-pipeline/uat_-_UAT
  • gs-pipeline/prod_-_Production

If your repo doesn't use Gearset, use the Standard or Extended presets above, or add environments manually below.

Direct commits to these branches are blocked. Users must create a new branch + PR instead.

Comma-separated, case-insensitive

📖 How to deploy a CORS Proxy (Cloudflare Worker)
  1. Go to Cloudflare Dashboard → Workers & Pages → Create Application → Create Worker
  2. Give it a name (e.g. sf-cors-proxy) and click Deploy
  3. Click Edit Code and replace the contents with the code below
  4. Click Save and Deploy
  5. Copy the Worker URL (e.g. https://sf-cors-proxy.your-account.workers.dev) into the field above
Cloudflare Worker code (copy & paste) 
export default {
  async fetch(request) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Headers': '*',
      'Access-Control-Allow-Methods': '*',
    };
    if (request.method === 'OPTIONS') return new Response(null, { headers: cors });
    const url = new URL(request.url);
    const target = url.pathname.substring(1) + url.search;
    if (!target.startsWith('https://')) return new Response('Bad URL', { status: 400 });
    const resp = await fetch(target, {
      method: request.method,
      headers: request.headers,
      body: request.method !== 'GET' ? await request.text() : undefined,
    });
    const newHeaders = new Headers(resp.headers);
    Object.entries(cors).forEach(([k,v]) => newHeaders.set(k, v));
    return new Response(resp.body, { status: resp.status, headers: newHeaders });
  }
}
Setup Instructions

Option A — External Client App (recommended):

  1. In Salesforce: Setup → External Client App Manager → New External Client App
  2. Name: SF Pipeline Tracker, Distribution State: Local → Save
  3. On the app page → OAuth Settings → Configure
  4. Callback URL:
  5. Scopes: Manage user data via APIs (api)
  6. Client Authentication: None (Public Client), PKCE: off
  7. Save → wait 2-5 min → copy the Consumer Key
  8. Paste the Consumer Key into the field above

Option B — Connected App (classic):

  1. Setup → App Manager → New Connected App
  2. Enable OAuth, set Callback URL (same as above), add scopes Api and RefreshToken
  3. Require Secret: off, PKCE: off → Save
  4. Wait ~2 min → App Manager → SF Pipeline Tracker → View → copy Consumer Key
  5. Paste the Consumer Key into the field above

For CORS Proxy: deploy a Cloudflare Worker (expand the section above for code)

⚡ Quick Setup: Create OAuth App

Option 1 — One-click deploy (regular Dev Orgs only)

Deploy a pre-configured Connected App. Works for standard dev orgs (login.salesforce.com). Does NOT work for Sandboxes or custom-domain orgs.

  1. Click the button above and log in to your org
  2. Wait ~2 minutes for activation
  3. Setup → App Manager → SF Pipeline Tracker → View → copy Consumer Key
  4. Paste the Consumer Key into the field above

Option 2 — External Client App (any org, including Sandboxes)

Create the app manually in Salesforce Setup. Works for all orgs including sandboxes and custom-domain orgs.

  1. In Salesforce: Setup → External Client App Manager → New External Client App
  2. Name: SF Pipeline Tracker, Distribution: Local → Save
  3. On the app page → OAuth Settings → Configure:
    • Callback URL:
    • Scopes: Manage user data via APIs (api)
    • Client Authentication: None (Public Client)
    • Require PKCE: off
  4. Save → wait 2-5 minutes for activation
  5. Copy the Consumer Key from the app page
  6. Paste the Consumer Key into the field above (or per-environment in Settings → Environments)
